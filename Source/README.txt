WordBook - Word-style notes app
1. Unzip this folder.
2. Double-click index.html (works offline in any modern browser).
Features: loading screen, books, lessons, white A4-style page, ribbon toolbar
(fonts, colors, lists, alignment, tables, charts: bar/pie/line/tree chart/tree diagram,
images, links, page breaks, symbols), download as HTML, print/PDF, auto-save.
Data is saved in your browser (localStorage).
